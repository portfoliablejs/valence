# Changelog

<br />

## [1.1.0] - 2026-08-04

<br />

### Added
- **Header Composition:** Added `ds-header` to PlayerView in the same top full-bleed position pattern used by CaseView/HomeView.
- **Breadcrumb Context:** Added internal breadcrumb rendering with fixed identity order: `Home`, `Case`, `Video`.
- **Title Inputs for Breadcrumb:** Added `case-title` and `video-title` attributes so the case name and active video name can be configured by the host.

### Changed
- **Navigation Region Visibility:** PlayerView keeps header navigation visible so accessibility actions remain directly available alongside breadcrumb context.
- **Non-Blocking Header Layout:** Header now overlays at the top viewport position and no longer pushes the player stage downward.
- **Dark Accessibility Readability:** PlayerView now enables the same `a11y-dark-mode` setting flow used by the design system so breadcrumb and navigation controls render with their native dark-mode styles.

<br />

## [1.0.0] - 2026-08-04

<br />

### Initial Release

The first stable release of `ds-player-view`, a template-level composition that pairs a video-rendering thumbnail frame with a fixed timeline, playback controls, and optional subtitles inside a single viewport shell.

<br />

### Added
- **Template Composition:** Added `ds-player-view` as a stateless wrapper around `ds-thumbnail`, `ds-seek-bar`, `ds-video-controls`, and `ds-subtitle` with a consistent viewport-level playback contract.
- **Video-Only Media Surface:** Added `screen-video`-only thumbnail integration so the thumbnail acts as the media surface for the embedded player.
- **Viewport Timeline:** Added a fixed top-bar seek surface using `ds-seek-bar` with `variant="top-bar"` and timestamp tooltip formatting.
- **Playback Orchestration:** Added synchronization between the native video element inside `ds-thumbnail`, the seek bar, and the control cluster for play/pause, mute, speed, stop, and captions.
- **Subtitle-Aware CC Visibility:** Added CC hiding when no subtitle source is configured so the control surface reflects actual media capabilities.
- **Adjustable Layout Hooks:** Added Storybook and CSS-variable controls for stage spacing, thumbnail sizing, controls width, and viewport padding so the layout can be tuned without introducing scroll.
- **Storybook Coverage:** Added PlayerView stories covering the default captioned case and the no-subtitle case.
- **Architecture Documentation:** Added a dedicated architecture page explaining composition principles, event flow, layout hooks, and accessibility boundaries.
